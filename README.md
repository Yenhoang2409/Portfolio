## 🚀 Dự án tiêu biểu: Sales Performance Dashboard
Dự án phân tích dữ liệu bán hàng thực tế từ các chuỗi cửa hàng điện tử lớn.

* **Mục tiêu:** Phân tích doanh thu, lợi nhuận và xác định xu hướng thị trường.
* **Công nghệ sử dụng:** ![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
    ![Pandas](https://img.shields.io/badge/pandas-%23150458.svg?style=for-the-badge&logo=pandas&logoColor=white)

### 📈 Các bước thực hiện:
1.  **Thu thập & Xử lý:** Làm sạch dữ liệu thô bằng Python (Pandas).
2.  **Lưu trữ:** Quản lý cơ sở dữ liệu qua SQLite.
3.  **Trực quan hóa:** Xây dựng Dashboard tương tác để theo dõi KPI.
4.  **Insights:** Đề xuất các giải pháp tăng trưởng dựa trên dữ liệu.
