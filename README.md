# My Personal Portfolio 🚀

Website cá nhân được xây dựng để tổng hợp các dự án và quá trình học tập trong ngành Công nghệ Thông tin.

## 🛠 Công nghệ sử dụng
- **Ngôn ngữ:** HTML5, CSS3 (Tailwind CSS)
- **Deployment:** GitHub Pages
- **Tools:** Git, Linux CLI, LaTeX

## 📁 Nội dung Portfolio
1. **Giới thiệu:** Thông tin sinh viên & định hướng Data Analyst.
2. **Dự án tiêu biểu:** - Dashboard phân tích doanh thu bán hàng.
   - Dự báo chuỗi cung ứng bằng Excel.
3. **Kỹ năng Digital:** SQL, Power BI, Tableau, LaTeX.
4. **Chứng chỉ:** Hoàn thành các khóa học LinkedIn Learning.
